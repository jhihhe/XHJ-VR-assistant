# 房堪上传

作者：@Jhih he

在房勘列表展开“上传房堪”，选择当日拍摄目录。程序仅解析下一层含完整HS编号的文件夹，末尾朝向应为东、南、西、北；备份目录和无编号目录忽略。核对图片数量及第一张客厅封面后，勾选所需房源，可先只读查询订单状态。

“重拍可上传”和“已接单可上传”为绿色，无效为红色。默认并发8，可选4、8、12、16、20。先完成封面，再并发上传余图，新图齐全且原订单未变化后保存；只填首个房间朝向。不要在原站一键清除后关闭窗口或空图确认。

状态文字可点击或用键盘打开详情。“保存未确认”表示尚无可靠保存确认，不能判定成功或失败；“已保存 · 回写待核实”表示服务器已确认图片保存，但订单回写未核实。失败后停止当前批次，不自动重复保存。请先到象视核对实际图片、封面、朝向及订单有效状态；再次上传需明确确认。

浏览器保存当前会话，服务器要求重新登录时仍需登录。脚本不能无用户授权读取本机目录，推荐路径按上海日期变化，目录仍需手动选择。核对记录只保存在当前浏览器本地存储，含订单编号、预期图片链接、朝向、阶段与错误，不含登录凭据或页面授权参数。清理网站数据会移除记录。

目前已完成重拍场景实站验证；尚缺新单首次上传实站样本。保留平台原有订单和照片，不把本地模拟当作服务器保存成功。
