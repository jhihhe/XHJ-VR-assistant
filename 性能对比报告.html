Pro 版模块架构

Module 0

核心工具库 (Core Utils)

EventBus 发布/订阅、debounce 防抖、rafThrottle RAF 节流、parseColorChannels 色彩解析、waitFor DOM 等待、$ / $$ 选择器

Module 1

设计系统与主题引擎

CSS 模板预编译 + Map 缓存、13 个设计令牌、CSS containment 隔离渲染、防闪烁关键 CSS 注入、iframe 主题同步

Module 2

性能优化引擎

单一 MutationObserver 合并、RAF 批量调度、快速过滤无关节点、定时回退扫描、内存管理销毁机制

Module 3

皮肤切换 UI

毛玻璃浮动面板、60fps 缩放动画、暗色/亮色分组、主题色块预览、内置缩放控制、点击外部关闭

Module 4

自动同步

async/await 异步流程、XPath + CSS 混合查找、进度状态提示、错误恢复、防重入保护

Module 5

自动缩放

智能检测上传/详情页自动禁用、响应窗口 resize、持久化比例设置、Toast 提示反馈

Module 6

表格增强

Proxy 拦截 layui.table.render（零侵入）、列配置持久化、状态行高亮、双击复制（Clipboard API）、内置保存按钮

Module 7

编排器 (Orchestrator)

分阶段初始化（立即 → DOM就绪 → iframe加载）、事件驱动生命周期管理、页面类型自动检测

Pro 版新增功能

📊

表格增强

Proxy 拦截 layui.table.render 实现零侵入式表格增强。支持列配置持久化（保存/恢复列顺序与显隐）、状态行智能高亮（待接单/已接单/无效分色显示）、双击行复制房源编号（Clipboard API + 降级方案）。

🔍

自动缩放

智能检测页面类型（上传/详情页自动禁用），响应窗口大小变化实时调整缩放比例。支持 +/- 微调按钮，比例持久化到 localStorage。使用 CSS zoom 属性实现，兼容所有浏览器。

🎨

主题色块预览

每个主题选项旁显示该主题的强调色色块，暗色/亮色主题分组展示。毛玻璃材质浮动面板，60fps 弹性缩放动画，点击外部自动关闭。

🔌

事件总线通信

轻量级发布/订阅模式，使用 queueMicrotask 异步调度，避免阻塞渲染。模块间完全解耦，支持主题变更、缩放调整、DOM 更新等事件。

💡

设计令牌体系

统一的设计变量管理：圆角（sm/md/lg/xl）、阴影（sm/md/lg/glow）、过渡动画（fast/normal/slow）。CSS Custom Properties 实现主题切换零重排。

🛡

性能优化引擎

CSS containment（contain: layout style paint）隔离布局计算，will-change 提示 GPU 加速，requestAnimationFrame 批量调度 DOM 更新，Map 缓存预编译 CSS 模板。
